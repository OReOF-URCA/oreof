# Dossier docs - index

Ce dossier contient la documentation interne du projet ORéOF. Objectif : centraliser les guidelines UI, procédures d'exploitation et notes d'architecture.

## Structure principale

- `ui-conventions/` : conventions UI, migration Tailwind et table de correspondance des icônes.
- `architecture/` : notes d'architecture, BDD et maquettes.
- `ops/` : procédures d'installation et commandes d'operation.
- `archives/` : documents historiques ou notes de travaux (à archiver ou nettoyer régulièrement).

## Composants symfony (twig)

- `composants/` : composants symfony (twig), avec des exemples d'utilisation et des explications sur leur architecture.
  - `composants/menu.md` : exemple d'utilisation du composant de menu, avec gestion des droits et pages de
    section. => [menu.md](composants/menu.md)
  - `composants/breadcrumbs.md` : exemple d'utilisation du composant de breadcrumbs, avec génération automatique à
    partir de l'arbre de navigation. => [breadcrumbs.md](composants/breadcrumbs.md)
